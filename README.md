# Lunaciia's Greenhouse

**本模组完全由 AI 制作。**

从 LUS 独立出的 Hypixel SkyBlock 温室种植编辑器与投影 Mod，不需要安装 LUS。
上述 AI 制作说明指本模组的开发与整合；引用的第三方代码、作物素材和数据归原作者所有，见 [来源与许可](THIRD_PARTY_NOTICES.md)。

## 功能

- 10×10 种植编辑器，作物图标网格、稀有度颜色与搜索。
- 土地贴图与独立编辑，可自动放置作物对应的土地。
- 多套本地预设、命名、切换、旋转、JSON 导入／导出。
- 导入 SkyShards Greenhouse 分享码或分享链接。
- 世界投影、自动定位与手动校准，作物使用白色轮廓框，突变作物使用立体轮廓框。
- 土地和图标区分正确、错误、缺失及未知状态。
- 编辑器内设置快捷键，中英文随游戏语言切换。

## 安装与使用

Minecraft **26.1.2**、Java **25**、Fabric Loader **0.19.5 或更高**，另需安装对应版本的 **Fabric API 0.155.3 或更高**。
将 Release 的 JAR 放入 `mods` 目录。

输入 `/greenhouse` 或 `/gh` 打开编辑器，也可在游戏按键设置中绑定「打开温室编辑器」。编辑器内的「设置快捷键」默认未绑定；Esc 取消绑定，Delete / Backspace 清除。

左键放置，种植模式右键同时移除作物及其占地上的土地；土地模式右键只移除土地。进入 Garden 已加载的温室后使用「开启投影」；如需手动定位，看向温室西北角土地并选择「手动校准」。

预设保存于 `config/lunaciia-greenhouse/`。首次启动会复制同实例中 `config/lus-greenhouse/` 的有效旧预设，不删除或修改原文件；之后两份预设独立保存。也可复制旧预设 JSON 到剪贴板后导入。

可以与 LUS 共装，命令、包名、贴图和配置互不覆盖。旧版 LUS 的温室入口仍然存在；同一时间只在其中一个 Mod 开启投影，以免重叠。

## 范围

仅编辑种植布局和显示投影，不模拟生长周期，不自动种植。识别只使用已加载的客户端数据。实服表现仍需用户确认，离线测试不等同于 Hypixel 实服验证。
